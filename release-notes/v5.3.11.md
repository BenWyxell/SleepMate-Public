# SleepMate 5.3.11

Release build: **5.3.11**.
Kiadási csatorna: **stable**.

A 5.3.11 a PWA O2Ring indulási/helyreállítási hibáit és a Dashboard oximetriai trend megjelenítését javítja.

## PWA O2Ring helyreállítás

- Az O2Ring funkció engedélyezett állapota és a hozzá tartozó dinamikus frontend modulok tényleges betöltöttsége külön ellenőrzést kap.
- Sikertelen O2Ring JavaScript-betöltés után a hibás script elem eltávolításra kerül, és a PWA automatikusan újrapróbálja a betöltést.
- `online`, `pageshow`, fókusz, láthatóvá válás és Service Worker shell-ready esemény után az alkalmazás az **engedélyezett, de hiányos O2 runtime** állapotot is helyreállítja.
- A Beállítások → O2Ring felület újrahidratálódik, ha a PWA hosszabb háttérben töltött idő vagy frissítés után félállapotban ébred fel.
- A hosszú életű 5.3.4 frontend-generáció többé nem törölhet aktuális 5.3.x release cache-t saját verziójelzője alapján; a shell cache-generáció takarítása a Service Worker feladata marad.

## Dashboard oximetria

- A Dashboard SpO₂- és pulzustrendje ugyanazt a napi trendrajzolót használja, mint az AHI trend.
- Az O2-adatok a Dashboard kiválasztott 7 / 30 / 90 napos vagy teljes időszakának napjaihoz igazodnak, ezért a hiányzó O2-napok nem csúsztatják össze a megmaradt pontokat.
- A két O2 trendkártya a normál Dashboard trendkártyák szerkezetét és méretezését követi, nem az élő Oximetria grafikonok nagy kártyás megjelenítését.
- Az összegző O2-mutatók továbbra is csak a ténylegesen elérhető, CPAP-idővel illesztett O2Ring napokból számolódnak.

## Kiadási ellenőrzés

A kiadás csak a hivatalos Windows release pipeline teljes build-, teszt-, MSI telepítési/runtime/eltávolítási és release-integritási ellenőrzése után publikálható.
