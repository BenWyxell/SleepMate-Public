# SleepMate 5.3.13

Release build: **5.3.13**.

Kiadási csatorna: **stable**.

## PWA Dashboard csomagolási javítás

A 5.3.12-ben elkészült mobilos PWA Dashboard redesign forráskódja megfelelő volt, azonban a Windows/MSI csomagolási folyamat a végleges `app.js` előállításakor felülírta azt a bootstrap réteget, amely a Dashboard új stylesheetjét betöltötte. Emiatt a telepített PWA gyakorlatilag a korábbi Dashboard elrendezést mutatta.

A 5.3.13 ezt a csomagolási hibát javítja:

- a `dashboard-pwa-v5312.css` közvetlenül bekerül a csomagolt PWA `index.html` fájljába;
- a stylesheet a Service Worker hálózat-first kódasset listájában is szerepel;
- regressziós teszt védi, hogy a PWA Dashboard stylesheet a jövőbeni MSI buildből ne maradhasson ki;
- a redesign továbbra is kizárólag a telefonos, telepített PWA Dashboardra vonatkozik, a desktop felület geometriáját nem módosítja.

A kiadás nem módosítja a terápiás adatok számítását vagy értelmezését.
