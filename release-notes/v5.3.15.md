# SleepMate 5.3.15

Release build: **5.3.15**.

Kiadási csatorna: **stable**.

## PWA napi Dashboard hotfix

Ez a kiadás a 5.3.14 két PWA-regresszióját javítja.

- A Részletes napi nézet mobilos bento Dashboard CSS-e most buildazonosítóval verziózott URL-ről töltődik, ezért iOS/PWA frissítés után nem maradhat bent a korábbi cache-elt elrendezés.
- A napi SpO₂- és pulzusértékek betöltése már nem függ attól, hogy az O2Ring UI runtime pontosan mikor fejezi be az aszinkron indulást.
- Ha az O2Ring frontend még nem áll készen, a napi Dashboard közvetlenül a napi O2 API-ról tölti be a szükséges összegzést, rövid újrapróbálással.
- A 5.3.14-ben bevezetett kompakt PWA napi Dashboard elrendezés megmarad; adat vagy funkció nem kerül elrejtésre.

A kiadás célja kizárólag a PWA napi Dashboard megjelenítési és O2-adatbetöltési regressziójának javítása.
